DatePickerDispatcher ​

Element Plus 的 el-date-picker 组件分发器，添加了只读功能。

选择某一天 ​

以”日“为基本单位，基础的日期选择控件

vue
<template>
  <el-radio-group v-model="size" aria-label="size control">
    <el-radio-button value="large">large</el-radio-button>
    <el-radio-button value="default">default</el-radio-button>
    <el-radio-button value="small">small</el-radio-button>
  </el-radio-group>
  <div class="mt-16px">
    <el-date-picker-dispatcher
      v-model="value1"
      type="date"
      placeholder="Pick a day"
      :disabled-date="disabledDate"
      :size="size"
    />
  </div>
</template>

<script lang="ts" setup>
import { ref } from "vue";

const size = ref<"default" | "large" | "small">("default");

const value1 = ref("");

const disabledDate = (time: Date) => {
  return time.getTime() > Date.now();
};
</script>

设置自定义前缀的内容​ ​

前缀内容可以被自定义。

当你从其他vue组件或由渲染函数生成的组件中导入组件时, 你可以设置 prefix-icon 属性来定制前缀内容

pre

vue
<template>
  <el-date-picker-dispatcher
    v-model="value1"
    type="date"
    placeholder="Pick a day"
    :prefix-icon="customPrefix"
  />
</template>

<script lang="ts" setup>
import { h, ref, shallowRef } from "vue";

const value1 = ref("");

const customPrefix = shallowRef({
  render() {
    return h("p", "pre");
  },
});
</script>

<style scoped>
.demo-date-picker {
  display: flex;
  width: 100%;
  padding: 0;
  flex-wrap: wrap;
}
.demo-date-picker .block {
  padding: 30px 0;
  text-align: center;
  border-right: solid 1px var(--el-border-color);
  flex: 1;
}
.demo-date-picker .block:last-child {
  border-right: none;
}
.demo-date-picker .demonstration {
  display: block;
  color: var(--el-text-color-secondary);
  font-size: 14px;
  margin-bottom: 20px;
}
</style>

Slots ​

使用 slots 中的 ${Config.namespace}Reader, ${Config.namespace}Writer 覆盖读写状态渲染函数。

writer: Mon Oct 05 2026 17:06:55 GMT+0800 (中国标准时间)
vue
<template>
  <div class="mt-16px">
    <el-date-picker-dispatcher
      v-model="value1"
      type="date"
      placeholder="Pick a day"
    >
      <template #[`${Config.namespace}Reader`]>
        <span style="color: green" key="reader">reader: {{ value1 }}</span>
      </template>
      <template #[`${Config.namespace}Writer`]>
        <span style="color: red" key="writer">writer: {{ value1 }}</span>
      </template>
    </el-date-picker-dispatcher>
  </div>
</template>

<script lang="ts" setup>
import { ref } from "vue";
import { Config } from "element-plus-form-dispatcher";

const value1 = ref(new Date());
</script>
